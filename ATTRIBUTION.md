# Data attribution

The primary English vocabulary catalog is imported from
[elzup/jlpt-word-list](https://github.com/elzup/jlpt-word-list), which is
distributed under the MIT License.

Copyright (c) 2020 Jamie Sinclair  
Copyright (c) 2020 elzup

The source repository acknowledges that its original deck data came from
`chyyran/jlpt-anki-decks`, based on decks from `tanos.co.uk`, and that it was
forked from `jamsinclair/open-anki-jlpt-decks`.

The small set in `assets/data/vocabulary.json` adds original Korean meanings
and example content to matching catalog records. The upstream list does not
provide Korean translations or example sentences.
