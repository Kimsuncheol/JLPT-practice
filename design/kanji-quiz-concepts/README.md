# Kanji quiz concepts

Figma: https://www.figma.com/design/2mCLVVytVGo2BBzivZYyh6?node-id=3-2

Four 390 × 844 mobile concepts: Match pairs (active and complete), Sort by reading (active and complete). The board uses the Flutter app's dark background, mint accents, coral selection, and butter/sky grouping panels.

The SVG board was imported successfully into Figma as vector artwork at node 3:2 and visually verified in the browser editor. This is a static mockup, not a wired prototype. The import does not provide native Auto Layout or reusable component variants. Individual screen SVGs and preview.png are included for review and reimport.
